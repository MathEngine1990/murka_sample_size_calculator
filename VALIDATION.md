# Проверка подготовленной версии

Дата: 29 октября 2026 года. Среда: Windows, R 4.5.1, PowerTOST 1.5-7, shiny 1.14.0, future 1.80.0, promises 1.5.0, ggplot2 4.0.3. Точные версии всех зависимостей сохранены в `renv.lock`.

## Автоматические проверки

Команда: `Rscript tests/verify.R` из папки приложения. Успешно прошли 29 проверок:

- Синтаксический разбор `app.R` и загрузка расчётной логики.
- Проверка допустимости 408 сочетаний сценариев, переключателей и дизайнов. Это проверка формирования спецификации, а не 408 независимых численных расчётов.
- Сравнение ABE с прямым вызовом `sampleN.TOST` для всех пяти дизайнов.
- Сравнение ABEL с прямым вызовом `sampleN.scABEL` для трёх репликативных дизайнов, включая CVwT = 30%, CVwR = 40%.
- Минимумы N, баланс последовательностей и поправка на выбывание.
- Полный стандартный расчёт: N = 28, с выбыванием N = 32.
- Полные расчёты NTI, биотехнологического ЛП, модифицированного высвобождения и ABEL.
- Воспроизводимость ABEL при фиксированном seed.
- Ограничение точек графика, включение итогового N, время результата и CVwT в сводке.
- Отклонение некорректных CV, мощности, выбывания, несовместимого дизайна и превышения лимита N.
- Реальный расчёт в отдельном процессе R при `workers = I(1)`.

## Проверка в браузере

Приложение запускалось на локальном адресе. Проверены:

- Стандартный сценарий: N = 28 и N = 32 с выбыванием; отображаются таблицы и график.
- ABEL по умолчанию: N = 46 и N = 56 с выбыванием 15%.
- Предупреждение при изменении CV после расчёта.
- Переход к параллельному дизайну: ранее введённый внутрииндивидуальный CV не переносится молча в межиндивидуальный.
- Две отдельные браузерные сессии с запросами ABEL и ABE получили собственные результаты без смешивания вводных.
- Копирование сводки подтвердилось уведомлением браузерного интерфейса.
- Повтор одинакового запроса вернул сохранённый результат с прежним временем вычисления.
- CV = 0 отклонён сервером с понятным сообщением; прежний результат отмечен как требующий пересчёта.
- Отображение на узком экране; широкая таблица допускает горизонтальную прокрутку.

## Границы проверки

- Размещение на GitHub и в Connect Cloud ещё не выполнялось. Установка Linux-зависимостей, лимиты памяти и доступ по публичной HTTPS-ссылке требуют проверки после публикации по `DEPLOYMENT.md`.
- Проверка фонового процесса и двух сессий не заменяет испытание под массовой нагрузкой.
- Лимит времени реализован средствами R и не является принудительным завершением процесса: некоторые нативные операции могут прерваться позже.
- Сравнение с PowerTOST подтверждает корректность передачи параметров в библиотеку. Оно не является независимой регуляторной валидацией сценариев, клинических допущений и применимости методологии к конкретному препарату.
